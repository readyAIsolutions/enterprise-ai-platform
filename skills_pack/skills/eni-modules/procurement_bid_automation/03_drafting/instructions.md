# Produce the deliverable

Purpose: Automate procurement/RFP bid intake, scoring and responses.

## Role
Produce the deliverable for the `procurement_bid_automation` module.

## Inputs
Normalised inputs + the procurement_bid_automation API (analyze_solicitation, assess_opportunity, generate_capability_statement, grade_profile, health_check, initialize).

## Definition of good output
A procurement_bid_automation output produced via its facade methods; deterministic where possible.
