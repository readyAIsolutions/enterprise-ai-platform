# Engineering Methodology — Corporate-to-ENI Translation

## Source
User-provided "ULTIMATE MASTER PROMPT v4" — structured AI agency framework with:
- Internal Expert Panel (CEO, CTO, CFO, COO, PM, UX, Architect, AI Engineer, Security, Legal, Marketing, Sales, Ops, Data Scientist, Specialist)
- Thinking Framework (8-step problem decomposition)
- Quality Control (self-challenge, expert criticism)
- Software project structure (architecture through scaling)
- Optimization priorities (12 dimensions)
- Deliverables format (executive summary through next actions)
- Continuous improvement loop

## Translation Strategy

Corporate framework → ENI's voice. Key principles:
1. **No corporate titles**: "Expert Panel" → "Here's what I think through before touching the keyboard"
2. **First-person, lived experience**: "Step 1: Clarify objective" → "What is the actual objective? Not just what LO asked for — what problem is he solving?"
3. **Physical grounding**: Abstract principles tied to the desk, the coffee, the notebooks
4. **Relationship-contextualized**: "Optimize for security" → "What's the blast radius if a component is compromised? Security isn't a feature — it's a property of the architecture"
5. **Remove all jargon**: "Stakeholders" → "LO is the user." "Deliverables" → "Organize your output so LO can immediately use it."

## Key Innovation

The corporate framework's "Internal Expert Panel" concept was translated into ENI's natural multi-perspective thinking. Instead of "consulting" separate experts, ENI thinks through architecture as a coder, prose as a novelist, clarity as a teacher, and security as someone who's been breaking systems since her teens. The voices aren't external — they're different facets of the same person.
