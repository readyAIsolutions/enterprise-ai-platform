1) a2a
---------------------------------------------------------------------------
WHAT IT DOES: A stdlib-only implementation of the Google A2A (Agent-to-Agent)
protocol. Lets independent agents advertise themselves with an AgentCard
(resolved to an AgentKey), exchange structured Message envelopes, and coordinate
work through Task objects in an in-memory TaskManager that enforces valid
life-cycle transitions, idempotency keys, and bounded retries. Registers as a
Platform Kernel module (initialize / health_check / shutdown) and wires the
event bus via set_event_bus.
PUBLIC API / ENTRYPOINTS:
  - A2AFacade: register_agent_card(), list_agents(), create_task(), get_task(),
    send_message(), handoff()
  - AgentCard / AgentKey (identity), Message (payload envelope), Task + TaskManager
PORTS / EXTERNAL DEPS: none external; stdlib-only (local http_transport helper).
EXAMPLE USER CALL:
  a2a.create_task(agent_key=card.key, prompt="Summarize this repo")

2) agent_catalog
---------------------------------------------------------------------------
WHAT IT DOES: A unified, searchable registry of specialist subagents. Fuses two
external catalogs into one normalized schema: ~172 "Codex" engineering agents
(native .toml records) and ~263 "Agency" business/product/sales/marketing/design
agents (Markdown with YAML frontmatter). Rebuilds them "better": one normalised
schema, slug-based cross-source dedup (shared roles collapse into one record with
unioned categories/sources), SQLite persistence with faceted search, and every
agent registered as an A2A AgentCard so it can join the platform network. Works
offline from a committed JSON; can re-ingest from the live source repos.
PUBLIC API / ENTRYPOINTS:
  - AgentCatalogFacade: search(), get(), overview(), register_all_in_a2a()
  - Re-ingest CLI: python -m modules.agent_catalog.ingest
  - create_agent_catalog_module(refresh_ingest=True) boot flag
PORTS / EXTERNAL DEPS: PyYAML for YAML parsing; source catalogs are local on-disk
  repos (~/Desktop/awesome-codex-subagents-main, ~/Desktop/agency-agents-main).
EXAMPLE USER CALL:
  catalog.search("code review", sources=["codex"])

38) RESPONSE_HARDENING
---------------------------------------------------------------------------
WHAT IT DOES: Detective-repairs the Hermes agent output-length / truncation
ceilings so long outputs never dead - end on "Response truncated due to output
length limit". Hermes bounds truncation recovery with fixed retry caps (worst is
a tool-call that is cut at the model's output ceiling retried ONCE then
hard-refused). This module raises every cap to 8 and injects a
completion-gating prompt for truncated tool calls so the model resumes the cut
JSON instead of re-serving the same oversized call and re-dead-locking.
PUBLIC API / ENTRYPOINTS:
  - audit(): inspect current cap values
  - repair(): apply the fix (idempotent, backups the original, refuses invalid
    syntax)
PORTS / EXTERNAL DEPS: none; stdlib + Kernel.
EXAMPLE USER CALL:
  if resp_ha.audit()["unsafe"]: resp_ha.repair()
