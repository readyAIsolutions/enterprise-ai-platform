  3. docs/UNIVERSAL_BUILD_SCORE_RESEARCH.md (the UBS numbers)
====================================================================
This doc is a RESEARCH / method-document, not a final computed UBS value.
It defines the universal 0-100+ build-quality score formula:
  UBS = 0.25*D1 + 0.15*D2 + 0.20*D3 + 0.15*D4 + 0.10*D5 + 0.15*D6 + BONUS
   D1 Reliability & Correctness (0.25)
   D2 Security & Supply-chain (0.15)
   D3 Maintainability & engineering (0.20)
   D4 Test quality (0.15, with test pass-rate HARD GATE <100% -> min(UB) 40,
     coverage banded: >=90 ->100, 80->90, 70->70, 50->45, <50->20)
   D5 Performance (0.10)
   D6 Documentation (0.15)
   BONUS allows exceed 100 up to +25 (excellence).
   HARD GATES: any real gate failing (secrets, failing tests, no real
   persistence, fake features) -> UBS = min(UBS, 40) => "unmarketable".
Read-out bands: 100+ Elite; 90-100 fully sellable; 70-89 strong; 50-69
functional but not sellable; <50/gated unmarketable.
There is NO single final "Universal Build Score = X" number printed anywhere
in the Enterprise_Validation tree. The 83% coverage + 3,135-tests / 177-pts
are separate metrics; the UBS framework only exists as a specification, so a
"Universal Build Score" should be derived and is currently UNAVERIFIED / unassigned.
